# Resource card

This file shows how a component-style doc can be expressed as static markdown.

```html
<a class="docs-card" href="/mcp">Open the SpecTrace docs index</a>
```

If a later project needs canonical markup, you can add that information to front matter and have the build map it into MCP resources.
